## 2. システム概要・目的
本機能は、ユーザーが日々の体重を簡単かつ正確に記録し、自身の体重推移を俯瞰して管理できるようにするためのものである。
日々の数値から、「前週の平均」「先月の平均」との差分を自動算出する。

---

## 3. 機能一覧
| 機能ID | 機能名 | 概要 |
| :--- | :--- | :--- |
| FT-WE-01 | 体重入力・登録 | 30.0kg〜150.0kgから選択して記録。同日の場合は自動更新。 |
| FT-WE-02 | 前回体重自動反映 | フォーム初期表示時、前回記録した最新の数値をデフォルト選択。 |
| FT-WE-03 | 直近履歴表示 | 直近1ヶ月の体重データ、および前週比・先月比を一覧表示。 |
| FT-WE-04 | 月別平均表示 | 月ごとの平均体重を算出し、新しい月順に一覧表示。 |

---

## 4. 画面レイアウト・UI仕様
画面（ルートパス: `/weight`）はスマートフォンでの操作を考慮し、中央に要素を集約したシンプルなカード型レイアウト（最大幅: `max-w-md`）を採用する。

### 4.1. 構成要素
1. **ヘッダー**: ⚖️ 体重記録
2. **日付表示**: 📅 日付: [yyyy-mm-dd形式（日本標準時）]
3. **入力フォーム**:
   * ラベル: `体重 (kg)`
   * セレクトボックス: 30.0〜150.0（0.1kg刻み）。デフォルトは前回体重。
   * ボタン: `記録する`（ブルー背景、ホバー時に明度を下げる）
4. **ナビゲーション**: `戻る` ボタン（前の画面への遷移）
5. **データ表示エリア（下部）**:
   * 📅 月別平均体重（テーブル形式）
   * 📊 直近1か月の記録（テーブル形式：前週比、先月比を含む）

---

## 5. 外部システム連携（データ永続化）
* **データストア**: Supabase
* **データアクセスルール**:
  * 画面ロード時に全レコードを日付降順で取得。
  * 登録時は、同日にデータが存在するかをチェックしてから処理を分岐（Upsert処理）。

---

## 6. 例外処理・エラーハンドリング
* **未選択バリデーション**: 体重が未選択の状態で登録を試みた場合、ブラウザアラートで「体重を選択してください」を表示し、DB通信を行わない。
* **通信エラー**: Supabaseとの通信に失敗した場合、ブラウザアラートで「登録失敗: [エラーメッセージ]」を表示する。
