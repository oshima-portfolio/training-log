# 基本設計書：ワークアウト記録画面

## 1. 概要
本画面は、日々のトレーニング（筋トレ）内容をリアルタイムに記録・保存するためのユーザーインターフェースである。ユーザーはトレーニング中に種目、重量、回数などを入力し、セット間のインターバルを計測しながら効率的に記録を行うことができる。

## 2. 画面レイアウト・構成
画面はスマートフォンの利用を想定したモバイルファースト（最大幅 `max-w-md`）の1カラム構成とする。全体の要素は垂直方向に適切な余白（`space-y-4`）を持って配置する。

### 画面要素・UIコントロール
1. **ヘッダーエリア**
   - タイトル: 「💪 筋トレ記録」
   - 実施日付: 本日の日付を表示（`📅 日付: YYYY-MM-DD`形式）
2. **インターバルタイマーエリア（`IntervalTimer`）**
   - グレーアウトされたブロック要素（`bg-gray-100`）内に配置。
   - タイトル: 「⏱️ インターバル」
   - **時間表示**: 残り時間を「分:秒」形式（等幅フォント `font-mono`）で中央に大きく表示。
   - **プリセットボタン群**: 2分（120秒）、3分（180秒）、5分（300秒）、テスト用（5秒）の4つのクイック設定ボタン。
   - **コントロールボタン群**: スタート（緑）、ストップ（黄）、リセット（赤）の操作ボタン。
3. **入力フォームエリア（`WorkoutFormInputs`）**
   - **種目**: セレクトボックス（必須。カテゴリ名付き表示。変更時に下部履歴テーブルと連動）
   - **ステータス**: セレクトボックス（必須）
   - **セット番号**: 数値入力（必須。ステータスが「メイン」の時のみ動的に表示）
   - **重量 (kg)**: セレクトボックス（必須。0kg〜300kgまで2.5kg刻み）
   - **回数 (rep)**: セレクトボックス（必須。1〜30回まで1刻み）
   - **備考（任意）**: テキストエリア
   - **種目順序**: 数値入力（必須。システム自動計算のため編集不可のグレーアウト表示）
4. **アクションボタン**
   - 「記録する」ボタン（フォーム保存）
   - 「戻る」ボタン（前画面への遷移）
5. **履歴表示エリア（`ExerciseHistoryTable`）**
   - 白背景のカード型UI（`bg-white`）内に配置。
   - 動的タイトル: 種目が選択されていれば「📌 {種目名} の全記録」、未選択なら「📌 選択種目の全記録」を表示。
   - テーブル形式（外枠・境界線付き）で過去のトレーニング実績の一覧をグリッド表示。

## 3. 機能一覧

| 機能ID | 機能名 | 説明 | 備考 |
| :--- | :--- | :--- | :--- |
| UC-001 | 記録入力UI | 種目、重量、レップ数、セット数等のワークアウト情報を入力・選択するUI。 | 重量・回数は選択式 |
| UC-002 | インターバル計測 | セット間の休憩時間をカウントダウンで計測・管理する。デフォルトは120秒。 | 分:秒形式で表示 |
| UC-003 | クイック時間設定 | プリセット（2分、3分、5分、テスト用5秒）から目標時間を素早くセットする。 | 変更時タイマーは停止 |
| UC-004 | インターバル通知 | タイマー満了時（0秒）に、ユーザーへバイブレーションと音声（アラーム）で通知する。 | 対応デバイスのみ |
| UC-005 | 履歴自動連動表示 | フォームの種目を選択・変更した際、その種目に応じた過去実績を自動取得し下部に表示する。 | 新しい順にソート |
| UC-006 | 記録保存 | 入力したデータをバリデーションの上、データベースに保存（送信）する。 | |
| UC-007 | オートインクリメント | ステータスが「メイン」の場合、保存成功時にセット数を自動で+1する。 | 利便性向上のため |
| UC-008 | 重量/セット数自動補完 | ステータスが「メイン」かつ種目選択時、前回重量と今日の次回セット数を自動補完する。 | 入力手間の削減 |
| UC-009 | 動的制御 | ステータスが「メイン」の時のみセット番号入力を表示。種目順序は常に読取専用とする。 | 誤入力防止 |
| UC-010 | 画面遷移 | 「戻る」ボタン押下時に、前の画面へ遷移する。 | |

## 4. データモデル定義（データストア連携）
本画面機能は、バックエンドデータストア（Supabase）の以下のテーブル群と連携を行う。

### 4.1 種目マスタ (`exercises`)
* `exercises_id` (主キー): 種目ID
* `name`: 種目名
* `category`: 種目カテゴリ

### 4.2 ステータスマスタ (`statuses`)
* `statuses_id` (主キー): ステータスID
* 属性情報（`*`）

### 4.3 トレーニングセット実績 (`sets`)
* `id` (主キー): レコード固有ID
* `date` (string): 実施日（YYYY-MM-DD形式）
* `exercise` (string): 種目名
* `status` (string): セットステータス
* `weight` (number): 重量
* `reps` (number): 回数（レップ数）
* `note` (string): 備考・メモ
* `set_number` (number | null): セット番号（ステータスが「メイン」の場合のみ記録。それ以外はnull）
* `exercise_order` (number): 種目の実施順序
